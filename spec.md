# Foot Rush

## Current State
Full e-commerce storefront with multi-color vibrant theme (deep indigo, teal, coral, emerald sections), animated gradients, glowing product cards, scrolling announcement bar. Backend stores products, orders, newsletter subscribers, and contact messages on-chain.

## Requested Changes (Diff)

### Add
- Vintage/retro typography (serif fonts, distressed or aged text styles)
- Worn paper / sepia texture feel for backgrounds
- Vintage color palette: aged cream, warm amber, burnt sienna, deep brown, faded gold, dusty rose
- Retro decorative elements: borders, dividers, badges with worn edges
- Film grain or noise texture overlay
- Old-school stamp / badge style for promotions and labels

### Modify
- Replace vivid multi-color section backgrounds with vintage muted tones (warm sepia, aged parchment, weathered brown, antique gold)
- Replace modern sans-serif fonts with classic serif/slab-serif vintage fonts (e.g. Playfair Display, Libre Baskerville)
- Update buttons to have rounded rectangle with thick borders, distressed look
- Announcement bar: dark brown/coffee background with cream text
- Navbar: deep warm brown or black with gold accents
- Product cards: parchment/cream cards with aged borders, vintage badge labels
- Footer: deep sepia/dark brown with aged cream text
- Hero section: aged parchment look with vintage typography and muted overlay
- Animations: keep but make subtle and slow (no flashy neon glows)

### Remove
- Neon/vivid gradient backgrounds
- Glowing neon card effects
- Bright saturated color sections

## Implementation Plan
1. Update global CSS with vintage color tokens, import Google Fonts (Playfair Display, Libre Baskerville)
2. Apply vintage palette to all sections: announcement bar, navbar, hero, products, categories, footer
3. Restyle product cards with parchment background, aged borders, vintage badge labels
4. Update buttons with vintage border style
5. Add subtle film grain/noise texture via CSS
6. Ensure all text remains readable with warm cream/white on dark backgrounds
